# Visualización de datos de vehículos usados

## Descripción del proyecto
Esta aplicación web fue desarrollada con Streamlit y permite explorar y visualizar
un conjunto de datos de anuncios de venta de vehículos usados.

La aplicación está orientada al análisis exploratorio de datos, mostrando información
de manera interactiva mediante una tabla y visualizaciones gráficas.

## Funcionalidad de la aplicación
La aplicación ofrece las siguientes funcionalidades:

- Carga del conjunto de datos `vehicles_us.csv`
- Visualización interactiva de la tabla completa de datos
- Botón para construir un histograma del kilometraje (`odometer`)
- Casilla de verificación para mostrar un histograma del precio (`price`)
- Visualizaciones interactivas creadas con Plotly


## Entorno de desarrollo
Se creó un entorno virtual llamado `vehicles_env`, el cual incluye las siguientes librerías:
- Pandas
- Plotly Express
- Streamlit
- nbformat (solo para simular graficos en jupyter)
